---
name: Site-wide page backgrounds
description: The web app should use near-white as the shared base surface across all pages.
---

Use the shared background token for each page's main surface, with a near-white appearance. Keep stronger colors for intentional sections, cards, and interactive elements.

**Why:** The user asked for the site's page backgrounds to lean white across all pages.

**How to apply:** When changing page backgrounds, prefer the global `--background` token instead of adding separate neutral colors to page-level wrappers.

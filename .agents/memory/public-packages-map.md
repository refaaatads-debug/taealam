name: Public packages map
description: User-approved privacy boundary for the visitor-facing in-person learning map.
---

The public packages page must use an illustrative, schematic map only. It must not display real locations, routes, or coverage availability.

**Why:** The user chose a conceptual map with explanatory design instead of data about actual locations.

**How to apply:** Keep map labels explicit that it is a visual illustration, and do not connect it to teacher location records.

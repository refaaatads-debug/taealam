---
name: Public packages map
description: User-approved privacy boundary for the visitor-facing in-person learning map.
---

The public packages page must use an illustrative, schematic map only. It must not display real locations, routes, or coverage availability.

When redesigning this page, treat the full page layout and information hierarchy as in scope—not just the map. The map should automatically explain the conceptual sequence from choosing an in-person lesson through arranging a booking to the teacher's travel and lesson, with clear motion controls.

**Why:** The user chose a conceptual map with explanatory design instead of data about actual locations.

**How to apply:** Keep map labels explicit that it is a visual illustration, and do not connect it to teacher location records. Preserve responsive page structure, visible booking/travel steps, and reduced-motion support.
